# 基金估值小程序

一个基金估值微信小程序，支持自选基金、持仓管理、实时估值等功能。

---

## ✨ 主要功能

### 1. 自选基金
- 实时查看基金估值、今日涨跌、近1年涨跌
- **新增**：如果持有该基金，将显示实时持有金额、今日盈亏及累计盈亏
- 快速搜索添加

### 2. 持仓管理
- 记录买入/卖出操作
- 自动计算收益
- 持仓成本分析

### 3. 基金搜索
- 支持代码/名称搜索
- 热门基金推荐
- 快速添加到自选

### 4. 持仓导入 ⭐
- **手动批量导入**：通过输入基金代码/名称、当前持有金额和累计收益，系统自动根据当前净值计算份额并批量导入。
- **拍照识别**：OCR自动识别持仓截图

**⚠️ 重要安全配置（必读）：**
为了防止密钥泄露，本项目不再在代码中硬编码 API Key。请在**微信云开发控制台**中配置环境变量：
1. 进入 `云开发控制台` $\rightarrow$ `云函数` $\rightarrow$ `baiduOCR` $\rightarrow$ `配置` $\rightarrow$ `环境变量`
2. 添加以下两个变量：
   - `BAIDU_API_KEY`: 填入您的百度 AI API Key
   - `BAIDU_SECRET_KEY`: 填入您的百度 AI Secret Key
3. 保存并重新部署云函数。

## 🎯 使用建议

### 手动批量导入
适合：
- 能够直接从持仓页面查看“总市值”和“总盈亏”的用户
- 少量基金的精确录入

录入字段：
- **基金代码或名称**：用于定位基金
- **持有金额 (元)**：当前持仓的总市值
- **持有收益 (元)**：该基金的累计盈亏

**核心逻辑**：
系统将根据录入的：持有金额 ÷ 当前净值 = 持有份额，无需手动计算复杂的份额和成本价。

流程：
1. 输入单个基金的金额和收益 → 2. 点击"添加到待导入列表" → 3. 重复添加多个基金 → 4. 点击"确认导入"

### 拍照识别
适合：
- 持仓数量较多
- 从其他平台导入
- 快速批量导入

技巧：
- 文字清晰可见
- 识别后手动检查
